# 智能题库生成系统 - 工作流程文档

## 一、完整三阶段流程（pdfbook.html）

```
用户上传：PDF 书籍 + PDF 考试大纲
                ↓
        ┌─────────────────┐
        │   第一阶段：书籍处理  │
        └─────────────────┘
                ↓
        1. PDF 转图片（每页一张 PNG）
        2. 提取 PDF 嵌入图片到 image/ 目录
        3. AI 识别前 30 张图片，提取目录结构
        4. 生成 00_目录.md
        5. 清理封面/版权页/目录页等非正文图片
        6. 正文图片重命名为 page_0001.png 等
        7. 按章节范围找到对应图片
        8. 10 张一批传给 AI 提取原文
        9. 生成 书籍第X章_xxx_原文.md
        10. 根据原文分块生成章节大纲
        11. 生成 书籍第X章_xxx_大纲.md
        12. 生成 00_汇总.md 和 处理进度.md
                ↓
        ┌─────────────────┐
        │  第二阶段：考纲处理   │
        └─────────────────┘
                ↓
        1. PDF 考纲转文字
        2. AI 清理考纲内容（删除废话、保留核心考点）
        3. 保存 考试大纲_原文.txt
        4. 更新 处理进度.md
                ↓
        ┌─────────────────┐
        │  第三阶段：生成题目   │
        └─────────────────┘
                ↓
        1. 遍历考纲各章节
        2. 找到对应书籍章节原文 + 大纲
        3. 根据原文长度计算题目数量（5-100 题）
        4. 原文分段（每段 4000 字符）
        5. 传给 AI：原文 + 章节大纲 + 完整考纲
        6. AI 生成题目（单选/多选/判断/填空/简答）
        7. 保存 题目第X章.md
        8. 生成 00_题目汇总.md
        9. 生成 finish.md 完成标记
```

## 二、仅书籍模式（only.html）

```
用户上传：PDF 书籍（仅一个文件）
                ↓
        ┌─────────────────┐
        │   第一阶段：书籍处理  │
        └─────────────────┘
                ↓
        （与 pdfbook.html 第一阶段完全相同）
                ↓
        ┌─────────────────┐
        │  第二阶段：考试大纲   │
        └─────────────────┘
                ↓
        ⏭️ 自动跳过
        处理进度.md 中标记为"已跳过"
                ↓
        ┌─────────────────┐
        │  第三阶段：生成题目   │
        └─────────────────┘
                ↓
        1. 遍历书籍各章节原文
        2. 读取对应章节大纲
        3. 根据原文长度计算题目数量（5-100 题）
        4. 原文分段（每段 4000 字符）
        5. 传给 AI：原文 + 章节大纲（无考纲）
        6. AI 生成题目
        7. 保存 题目第X章.md
        8. 生成 00_题目汇总.md
        9. 生成 finish.md 完成标记
```

## 三、快速题目模式（fast.html）

```
用户上传：PDF 考试大纲
                ↓
        1. PDF 全文转文字（不分章节）
        2. 提取"课程内容与考核要求"部分
        3. 清理垃圾内容（评分方式、考试说明等）
        4. AI 直接生成 500 道题目
        5. 保存到 output/文件名/文件名.md
        6. 生成 finish.md 完成标记
```

## 四、目录识别逻辑

### 4.1 输入

- PDF 前 30 页图片

### 4.2 AI 识别

支持多种章节格式统一转换为"第X章"：

| 原始格式 | 转换后 |
|---------|--------|
| 第1章、第一章 | 第1章 |
| 1. 第一章 | 第1章 |
| Module 1、Unit 1 | 第1章 |
| 项目一、项目1 | 第1章 |
| 专题一、教学单元1、单元1 | 第1章 |

### 4.3 过滤规则

自动过滤以下非正文章节：

- 版权、扉页、前言、序言、编写说明
- 实验、实训、实践、习题、练习、案例
- 附录、参考文献、后记、致谢
- 空白页、题型举例、程序分析题、程序设计题
- 目录、索引、封底

### 4.4 页码计算

- AI 返回章节起始页码
- 结束页码 = 下一章起始页码 - 1
- 最后一章结束页码 = PDF 总页数

## 五、题目生成逻辑

### 5.1 题目数量

| 原文长度 | 题目数量 |
|---------|---------|
| < 1000 字 | 5 题 |
| < 3000 字 | 10 题 |
| < 6000 字 | 20 题 |
| < 10000 字 | 35 题 |
| < 20000 字 | 50 题 |
| < 40000 字 | 70 题 |
| ≥ 40000 字 | 100 题 |

### 5.2 题型比例

| 题型 | 比例 |
|------|------|
| 单选题 | 40% |
| 多选题 | 20% |
| 判断题 | 15% |
| 填空题 | 15% |
| 简答题 | 10% |

### 5.3 分段处理

- 原文超过 4000 字符时自动分段
- 每段单独传给 AI 生成题目
- 题目编号连续递增

## 六、任务队列

### 6.1 队列配置

| 模式 | 最大排队数 |
|------|-----------|
| pdfbook / only | 50 个 |
| fast | 10 个 |

### 6.2 队列特性

- 单线程依次处理，避免 AI 并发压力过大
- 支持后台运行，关闭浏览器不影响
- 提供 SSE 实时进度推送
- 提供 REST API 状态查询

## 七、输出文件说明

### 7.1 书籍处理输出

| 文件 | 说明 |
|------|------|
| 00_目录.md | 目录信息 |
| 00_汇总.md | 章节汇总 |
| 00_题目汇总.md | 所有题目汇总 |
| 处理进度.md | 三阶段处理进度 |
| finish.md | 完成标记（空文件） |
| 书籍第X章_xxx_原文.md | 章节原文 |
| 书籍第X章_xxx_大纲.md | 章节知识大纲 |
| 题目第X章.md | 生成的题目 |

### 7.2 Fast 输出

| 文件 | 说明 |
|------|------|
| 文件名.md | 500 道题目 |
| finish.md | 完成标记 |
