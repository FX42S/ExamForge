# 智能题库生成系统 - 故障排查

## 一、PDF 处理失败

### 1.1 OTF 字体渲染错误

**现象**:

```
java.lang.UnsupportedOperationException: OTF fonts do not have a glyf table
```

**原因**: PDFBox 不支持某些 OTF 字体。

**解决**: 系统已自动使用文本兜底渲染，无需手动处理。如果仍然失败，检查 `PdfConverter.java` 的异常捕获。

### 1.2 PDF 页数识别错误

**现象**: 目录页码范围异常，如 `43-12`。

**原因**: AI 返回的页码格式不规范。

**解决**: 系统已改进 Prompt 和解析逻辑，要求 AI 只返回起始页码。如仍有问题，检查 `parseTableOfContents()` 和 `filterNonChapterEntries()`。

### 1.3 章节识别遗漏

**现象**: 某本书的章节没有被识别。

**原因**: 章节格式不在支持列表中。

**解决**: 在 `PdfBookAnalysisService.analyzeTableOfContents()` 的 Prompt 和 `parseChaptersBackup()` 的正则中添加新格式。

## 二、题目生成问题

### 2.1 题目编号重复

**现象**: 生成 1-250, 1-250。

**原因**: 分段处理时没有传递起始编号。

**解决**: 已修复，每次分段后更新 `currentQuestionNumber`。

### 2.2 生成无关题目

**现象**: 题目包含"评分方式"、"考试时间"等。

**原因**: 考纲中包含垃圾内容。

**解决**: Fast 模式已增加清理逻辑，提取"课程内容与考核要求"部分。

### 2.3 题目数量不对

**现象**: 某章题目太少或太多。

**原因**: 原文长度计算或分段逻辑问题。

**解决**: 检查 `TaskQueueService.calculateQuestionCount()` 和 `splitTextIntoChunks()`。

## 三、队列问题

### 3.1 任务不执行

**现象**: 任务一直 pending。

**原因**: 队列处理器未启动。

**解决**: 重启服务，检查日志中是否显示"队列处理器已启动"。

### 3.2 关浏览器后任务停止

**现象**: 关闭浏览器后任务不再执行。

**原因**: 队列处理器使用了非静态变量。

**解决**: 已修复为静态变量，确保后台持续运行。

### 3.3 队列已满

**现象**: 提交任务返回"等待处理的任务过多"。

**原因**: 队列达到上限。

**解决**: 等待任务完成，或修改 `TaskController` 中的上限值。

## 四、AI 调用问题

### 4.1 AI 连接失败

**现象**: 调用 AI 超时或返回 404。

**原因**: LM Studio 未启动或配置错误。

**解决**:

1. 检查 LM Studio 是否运行
2. 检查 `config.json` 中的 `lmstudio.base.url` 和 `lmstudio.api.path`
3. 检查模型名称是否正确

### 4.2 AI 响应解析失败

**现象**: 日志显示"无法解析章节"或"目录为空"。

**原因**: AI 模型输出格式不规范。

**解决**:

1. 检查 AI 原始响应日志
2. 在 Prompt 中更严格地要求格式
3. 增强后端解析逻辑

## 五、前端问题

### 5.1 页面打不开

**现象**: 访问 `http://localhost:8188` 显示 404。

**原因**: 服务未启动或端口错误。

**解决**:

1. 检查服务是否启动
2. 查看 `application.yml` 中的端口配置
3. 查看是否有其他程序占用 8188 端口

### 5.2 SSE 连接断开

**现象**: 页面显示"连接断开，正在重连"。

**原因**: 网络或服务问题。

**解决**: 系统会自动重连，无需手动处理。如持续断开，检查服务状态。
